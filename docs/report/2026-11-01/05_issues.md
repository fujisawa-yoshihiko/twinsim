## 人数の流れ

「入口の何人が何分後に EV 前に現れるか」を、仮想のオフィス（5 分・94 人・カメラ 2 台、[twinsim](glossary.md#twinsim)）で確かめた。手順の確認で、竹芝での性能の見込みではない。

| 指標 | 値 |
|---|---|
| ゲートの人数の[誤差](glossary.md#mae) | 0.63 人（平均 2.3 人） |
| ゲートの方向の [F1](glossary.md#f1) | 0.93 |
| EV 前の人数の誤差 | 0.60 人（平均 4.5 人） |
| EV 待ち人数の誤差 | 1.03 人 |
| 入館から 5 分以内に EV 前に現れた割合 | 正解 0.90・推定 0.85 |
| 現れるまでの秒（中央値） | 正解 12.4・推定 12.4 |

場面と仕組みの詳しい説明は [10/24 の報告](../2026-10-24/README.md)と[検知と 2 地点の紐付けの仕組み](../../methods.md)。
