## 素材と出典

- 映像はすべて [NVIDIA Isaac Sim](glossary.md#isaac-sim) で作った仮想空間。竹芝の映像・図面は使っていない。
- 空間: Isaac Sim の Hospital・Office（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）。人物を置いて描画し、カメラの映像にした。
- 人物: Isaac Sim 付属の仮想の人物モデル（10 種類）。服の色を変えていない場面だけを載せた。
- VLM はローカルの GPU で実行し、映像を外部に送っていない。

人物モデルの利用条件（2026-11-01 に確かめた範囲。法務の確認ではない）:

- モデルのフォルダに LICENSE のファイルはなく、[NVIDIA Isaac Sim Additional Software and Materials License](https://docs.isaacsim.omniverse.nvidia.com/6.1.0/common/license-isaac-sim-additional.html) の対象。
- その条件が制限するのは素材そのものの配布と改変で、描画した映像には触れていない。
- [License FAQ](https://docs.isaacsim.omniverse.nvidia.com/6.1.0/common/license-faq.html) は、内部で動かしたシミュレーションの出力（映像・レポート・データ）だけなら追加のライセンスは不要としている。

## この報告の作り方

ページは研究のフォルダ（`~/MOPF_ALL_video/research/slides/partner_update_2026-11-01/`、手元の git だけ）の `build_github_report.py` が、原稿 `github_src/` と結果のファイルから作る。
数値は手で写していない。映像の切り出しは同じフォルダの `make_videos.py` の出力から作る。CPU だけで、GPU は使わない。
